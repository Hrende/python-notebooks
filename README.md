
# Python Notebooks and Scripts

Python practice from my self-directed learning, alongside my degree in Molecular Biology and Genetics. Some files were written with AI assistance (Gemini and Claude) while learning, and I work through the code to understand it.

## Contents

- `python_comprehensive_course.ipynb`: Python course notes and exercises
- `Python_work.ipynb`: Additional practice exercises
- `dna_analysis.py`: GC content, transcription and translation of a DNA sequence
- `sequence_alignment.py`: Pairwise alignment of a wild-type and a mutant DNA fragment with Biopython (score and percent identity)

## Tools

Python, Jupyter Notebook (Anaconda), Biopython
